## RFC Lifecycle

```
Draft → Review → Accepted → Implemented → Deprecated
```

| 상태 | 의미 |
|---|---|
| 📝 Draft | 초안 작성 중 |
| 🔍 Review | 팀 리뷰 진행 중 |
| ✅ Accepted | 채택 확정 |
| 🚀 Implemented | 구현 완료 |
| ⛔ Deprecated | 폐기 |
